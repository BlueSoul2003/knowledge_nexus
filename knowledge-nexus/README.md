# Knowledge Nexus

**[🌍 Visit the Live Site Here](https://fp-physics-team.github.io/knowledge-nexus)**

Welcome to **Knowledge Nexus**! This is an open-source, interactive repository of knowledge bridging various domains like Physics, Economics, Business, Management, Psychology, Metaphysics (玄學), 3D Printing, Electronics, and more. 

## Vision
The goal is to move beyond static textbooks. Knowledge Nexus serves as a *grand landing page* that hosts standalone, interactive HTML modules created by learners, educators, and researchers around the world.

## How to Contribute
We welcome everyone to build and submit their interactive experiments! Since the project architecture is extremely simple, you don't need to learn a complex framework to contribute.

To get started quickly, we provide a starting module template at `templates/module-template/`.

**[👉 Read the full Contribution Guide here](CONTRIBUTING.md)** for step-by-step instructions on creating, styling, and registering your module.

## Local Development
Since this uses standard HTML, CSS, and JS, you can run this locally using any simple HTTP server:
```bash
npx serve .
# or
python3 -m http.server
```
